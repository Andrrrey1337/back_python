# Вариант 20 — этап 1

Модель слоя доступа к данным.
Все записи хранятся в списках в памяти.

## Реализовано

Для `Person`, `Instruction` и `Answer`:

- создание записи;
- получение всех записей;
- получение записи по идентификатору.

Дополнительно реализована выборка `Answer.output` и `Instruction.description`
для ответов, созданных за последние 8 минут, с соединением по
`Instruction.identifier = Answer.instruction`.

Также реализован REPL и обработка ошибок.

## Запуск

```bash
./run.sh
```
